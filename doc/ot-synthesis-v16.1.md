# Open Tree of Life version 16.1

Version 15.1 of the synthetic tree was generated on 20 June 2025 using the [propinquity pipeline](https://github.com/OpenTreeOfLife/propinquity) SHA fd64fe6643ea082bf350fce46750d1253e383bd5.

## Downloads
There are two downloads. The first (smaller download) contain only tree and annotations files. The second (larger download) is the full output from the synthesis procedure, including documentation. You can also [browse the full output](https://files.opentreeoflife.org/synthesis/opentree16.1/output/index.html).

* [Tree and annotations](https://files.opentreeoflife.org/synthesis/opentree16.1/opentree16.1_tree.tgz) : Several versions of the synthetic tree, along with the annotations file. See the enclosed README for details. (compressed tar archive; 38 Mbytes)
* [All pipeline outputs](https://files.opentreeoflife.org/synthesis/opentree16.1/opentree16.1.tgz) : Outputs and documentation from all stages of the synthesis pipeline. Or, you can [browse the output](https://files.opentreeoflife.org/synthesis/opentree16.1/output/index.html) rather than downloading. (compressed tar archive; 497 Mbytes)
